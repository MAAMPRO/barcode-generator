# Barcode & QR Studio

A lightweight, browser-based utility for generating linear retail/inventory barcodes (**Code 128**, **UPC-A**, **EAN-13**, **Code 39**) and **2D QR Codes** with custom colors and instant PNG export.

## Features
- **Multi-Format Support:** Switch between Code 128, QR Code, UPC-A, EAN-13, and Code 39 with automatic sample presets.
- **Live Validation:** Built-in checksum and format validation for standard retail symbologies.
- **Instant Export:** One-click high-resolution PNG download.
